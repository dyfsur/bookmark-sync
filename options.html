书签坚果云同步

通过坚果云 WebDAV 在 Chrome / Edge 之间同步书签，保留原始结构与顺序

坚果云登录账号邮箱
坚果云 → 账号信息 → 安全选项 → 添加应用密码。建议权限只勾选「写入文件」。
书签变化后也会自动触发同步（5 秒防抖）。此值控制定时兜底。
数据文件会保存在坚果云的该文件夹下，不污染根目录。留空则用默认「Bookmarks」。
如何获取坚果云应用密码？
  1. 登录 坚果云官网
  2. 点击右上角头像 → 账号信息
  3. 左侧 安全选项 → 第三方应用管理
  4. 点击 添加应用密码，任意命名（如 "bookmark-sync"）
  5. 复制生成的应用密码（形如 abcd1234 的随机串），粘贴到上方
