# 书签坚果云同步（Bookmark Sync via Jianguoyun）

在 Chrome 和 Edge 之间，通过坚果云 WebDAV 双向同步书签的浏览器扩展。**完整保留浏览器书签的原始层级、文件夹结构和顺序**（不是垂直书签那类改造），支持自动去重、自动双向合并与删除传播。

> ⚠️ **非商用开源**：本项目使用 [CC BY-NC-SA 4.0](LICENSE) 协议，允许个人学习、使用与修改，**禁止商用**。

## 特性

- **原生书签形态**：同步的是浏览器书签树本身，书签栏、书签管理器的展示与手动添加完全一致
- **自动去重**：URL 规范化（去 `#`、去默认端口、排序查询参数）后做指纹，重复书签自动折叠进「重复书签」文件夹备份，不直接删除
- **自动双向合并**：多台电脑各自增删改都保留，以修改时间新的标题为准
- **删除传播 + 墓碑**：一边删掉的书签/文件夹，另一台设备不会自动复活；「删除后重新新建」的同名节点会被正确保留（按创建时间区分）
- **跨浏览器兼容**：自动识别 Chrome/Edge 根文件夹的本地化命名差异（如「书签栏」与「收藏夹栏」），数据可互相同步
- **全自动同步**：书签一变就同步（5 秒防抖）+ 定时兜底（默认 15 分钟）
- **WebDAV 直连**：不依赖坚果云本地客户端，任何装了扩展的电脑都能同步
- **并发安全**：版本号 + 写前重读，多台电脑同时同步不会互相覆盖
- **安全护栏**：应用失败时不会用缩水数据覆盖云端，保护已有数据

## 安装

### 方式一：加载已解压扩展（推荐，最简单）

1. **获取坚果云应用密码**（只需一次）：
   - 登录 [坚果云官网](https://www.jianguoyun.com)
   - 头像 → **账号信息** → **安全选项** → **第三方应用管理**
   - **添加应用密码**（命名随意，如 `bookmark-sync`），复制生成的应用密码
2. **加载扩展**：
   - Chrome：打开 `chrome://extensions` → 打开右上角**开发者模式** → **加载已解压的扩展程序** → 选择 `bookmark-sync-extension` 文件夹
   - Edge：打开 `edge://extensions` → 打开左侧**开发人员模式** → **加载解压缩的扩展** → 选择该文件夹
3. **配置**：
   - 点击扩展图标 → **打开设置**
   - 填入坚果云用户名（邮箱）+ 应用密码 → **保存并立即同步**
   - 点「测试连接」可先验证 WebDAV 是否连通
4. **选择同步目录（可选）**：
   - 默认数据保存在坚果云 `Bookmarks/` 目录
   - 想放到指定文件夹（如 `我的文档/书签`）：在设置的「同步目录」里填写路径，或点「浏览…」用目录浏览器选择
   - 留空则使用默认 `Bookmarks`
5. **在另一台电脑重复 2-4 步**，使用**同一个坚果云账号**、**同一个同步目录**

### 方式二：安装打包好的 .crx

> 浏览器对非商店来源的 .crx 有严格限制。**首次安装前必须确保扩展目录未被修改**，否则签名校验失败。

1. 从 [Releases](../../releases) 下载 `bookmark-sync.crx`
2. Chrome/Edge 打开扩展管理页，开启开发者模式
3. 将 `.crx` 文件拖入扩展管理页窗口
4. 按提示确认安装

> 由于 crx 签名绑定固定私钥，**不建议直接分发 crx**。若需分发，请用「加载已解压扩展」方式，或提供 `bookmark-sync.zip` 让用户自行解压后加载。

### 方式三：zip 包

解压 `bookmark-sync.zip`，按「方式一」的步骤加载解压后的文件夹。

## 使用说明

- **同步触发**：书签增删改/移动后 5 秒自动同步；另有定时兜底（默认 15 分钟，可在设置里改）
- **手动同步**：点扩展图标 → 「立即同步」
- **重复书签**：同步时发现重复 URL，保留最先出现的那个，其余移入「重复书签」文件夹，方便手动清理
- **诊断**：点扩展图标 → 「诊断」，可查看本机书签、云端数据、同步日志，用于排查问题
- **多台电脑**：任意一台的改动都会自动合并到云端，再下发到其他电脑

## 工作原理

```
┌─────────┐  读取书签树  ┌────────────────┐  双向合并   ┌────────────────┐
│ 本机浏览器 ├──────────►│  merge.js 算法  ├───────────►│  坚果云 WebDAV  │
│ (Chrome/ │  应用合并   │  去重+墓碑+别名  │  版本控制    │ bookmarks_sync │
│  Edge)   │◄───────────│                │◄───────────│     .json      │
└─────────┘             └────────────────┘             └────────────────┘
```

- **序列化**：`serializeTree` 把浏览器书签树转成可存储 JSON，保留层级与顺序
- **去重**：规范化 URL → FNV-1a 指纹，重复书签移入「重复书签」文件夹
- **双向合并**：以远端为基底合并本地差异；URL 指纹匹配书签、标题匹配文件夹
- **墓碑**：删除的书签/文件夹记录删除时间，30 天内不复活；新建节点（创建时间晚于墓碑）优先保留
- **根别名归一化**：`书签栏`/`收藏夹栏` 等本地化根名统一映射到 `bar/other/mobile`，跨浏览器一致
- **版本控制**：数据文件 `_version` 递增 + 写前重读，检测并发修改后自动重新合并

## 文件结构

```
bookmark-sync-extension/
├── manifest.json      # MV3 清单（权限：bookmarks, alarms, storage + 坚果云域名）
├── background.js      # 同步引擎（Service Worker）
├── merge.js           # 合并/去重/墓碑/根别名/应用回浏览器算法
├── webdav.js          # 坚果云 WebDAV 客户端（GET/PUT/PROPFIND/MKCOL）
├── options.html/js    # 设置页（账号、间隔、同步目录）
├── popup.html/js      # 扩展弹窗（状态、手动同步、诊断）
├── icons/             # 图标
└── tests/
    └── merge.test.js  # 核心算法测试
```

## 数据格式（远端 `bookmarks_sync.json`）

```json
{
  "tree": [
    {
      "title": "书签栏",
      "children": [
        { "title": "Example", "url": "https://example.com", "created": 1234567890 }
      ]
    }
  ],
  "_tombstones": { "/bar/旧文件夹": 1715000000000 },
  "_version": 42,
  "_instance": "inst_...",
  "_updatedAt": 1234567890,
  "_schema": 2
}
```

字段说明：

- `tree`：书签树（保留层级、顺序）
- `_tombstones`：删除墓碑（路径/指纹 → 删除时间戳）
- `_version`：数据版本号（并发控制）
- `_instance`：上次写入的设备实例 ID
- `_schema`：数据格式版本

## 隐私与安全

- 扩展只访问 `dav.jianguoyun.com`（坚果云 WebDAV）和浏览器书签数据
- 应用密码只存在浏览器扩展的本地 `chrome.storage.local`，不会上传到任何第三方
- 应用密码在坚果云后台可以随时撤销

## 已知限制

- **书签栏 UI 状态**（图标、是否显示书签栏等）是浏览器内部偏好，书签 API 不暴露，无法同步
- 扩展不监控书签栏本身的"显示/隐藏"，这属于浏览器设置
- 去重基于规范化 URL。URL 完全相同但标题不同的两条书签会被视为重复（保留第一条）
- 若两台电脑**几乎同时**改了同一批书签，靠版本号检测冲突后自动重新合并，理论上不会丢数据

## 开发

```bash
# 语法检查
node --check background.js merge.js webdav.js options.js popup.js

# 核心算法测试（合并/去重/墓碑/根别名）
node tests/merge.test.js

# 打包 crx/zip（需要 npm install crx node-rsa）
node pack-crx.js dist/clean dist/bookmark-sync.pem
```
